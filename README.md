# The Listening Room

An interactive guide to 17 musical instruments, with photographs, explanations, demonstrations, and 34 featured compositions.

## Open the website

After GitHub Pages is enabled, use the website address shown in this repository’s **Settings → Pages**.

## Files

- `index.html` contains the complete website: instrument information, styling, and navigation.
- `.nojekyll` tells GitHub Pages to serve the website files directly.
- `README.md` is this guide. It does not appear as a page in the website.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Source**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/(root)` folder, then click **Save**.
4. Wait for publishing to finish and use **Visit site**.

## Make a small change

1. Open `index.html` on GitHub and click the pencil to edit it.
2. Find the text you want to change. Each instrument is listed in the `instruments` array.
3. Save with **Commit changes**. GitHub Pages republishes the website automatically.

The site uses external photographs, Google Fonts, and listening/demonstration links. Access to those services depends on the visitor’s network. Image credits and original source links remain beside each photograph.

## Preview on your computer

Download the repository and open `index.html` in a browser. No installation or build step is needed. Use instrument buttons, Previous/Next, or the left/right arrow keys to browse.
